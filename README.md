# 中小企業向け AI業務効率化アシスタント導入プロジェクト

## 概要
本プロジェクトは、中小企業・店舗運営者向けに、
問い合わせ対応や予約受付などの業務をAIで効率化することを目的とした
業務自動化アシスタントの導入を想定したポートフォリオ案件です。

## 想定クライアント
- 地方の飲食・サービス業
- 従業員数：約15名
- 複数名でシフト制運営

## 現状の課題
- LINEや電話による問い合わせ対応が多く、営業時間中の業務負荷が高い
- 予約情報が口頭・紙・LINEなど複数の手段で管理されている
- 新人スタッフが同じ内容の質問を繰り返し確認する必要がある

## 要件定義
### 必須要件
- LINE上で問い合わせに自動対応できること
- 予約受付を自動化し、一覧で管理できること
- 非エンジニアでも運用・管理が可能であること

### 非要件
- 決済機能は対象外
- 大規模トラフィックへの対応は想定しない

## システム構成と処理フロー
1. ユーザーがLINE公式アカウントにメッセージを送信
2. メッセージ内容をDifyに送信し、意図を判定
3. FAQで対応可能な内容はAIが自動返信
4. 予約に関する内容はGASに連携し、予約情報を整形
5. 予約データをGoogle Spreadsheetに保存
6. 必要に応じて管理者が内容を確認・対応

## 使用技術
- Python
- Dify
- Google Apps Script (GAS)
- LINE Messaging API
- Google Spreadsheet

## 設計上の工夫
- 曖昧な質問に対してはFAQではなく人対応に切り替える設計
- 非エンジニアでも内容を更新できるよう、データ管理はスプレッドシートを採用
- 運用コストを抑えるため、GASを中心とした構成とした

## 実装（MVP）

まずは最小構成として、
ユーザーの質問に対してAIが自動で回答する機能を実装した。

PythonスクリプトからAI APIを呼び出し、
質問内容に応じた回答を返す構成とすることで、
今後LINE連携や予約処理への拡張が可能な設計としている。
